# korea-forecast-bench

한국 날씨, 누가 제일 잘 맞추나? 기상청과 해외 예보 모델의 한국 예보를 매일 실제 관측과 대조해 채점한다.

## 데이터 출처

| 소스 | 용도 | 라이선스 |
|---|---|---|
| 기상청 단기예보 (공공데이터포털) | 국내 예보 | 확인 필요 |
| Open-Meteo (ECMWF·GFS·ICON·JMA 등) | 해외 예보 | 확인 필요 |
| 기상청 ASOS (공공데이터포털) | 실제 관측 | 확인 필요 |

코드는 [MIT](LICENSE). 데이터는 각 소스의 이용 조건을 따른다.
